What changes in Everyday

Same app, same tokens, same Pebble. Words get plainer, developer detail moves behind Developer mode. Nothing is removed.

Behind Advanced → Developer mode

  • Change cards (branch, CI, PR, commits, files, diff); Log, Files and Tasks tabs; tasks and claims.
  • Approval details (exact command, risk, source #N); message numbers; sessions; agent files; connect-any-agent setup.

How Developer mode stays

  • One switch in Settings › Advanced. It turns on by itself when you connect a coding agent (Claude Code, Codex).
  • It's per person: in one chat Sam sees the change card while Priya sees “Holiday hours are ready”. Same data, two renderings.
  • Developer mode is exactly today's app, so nothing regresses for us.
