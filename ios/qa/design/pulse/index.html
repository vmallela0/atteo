Pulse

The iPhone app's fast mode. Classic stays identical to the web app; the toggle is in the corner.

Try it

  • Tap a board. The other two fly away, it settles on top, the composer slides up.
  • Type @ for agent chips; mentions light up in clay. Type / for commands (/task, /decide). No type picker.
  • Send. The message flies into the agent's Pebble; its ring blips, then read, then 🤔, then a one-line reply under the card.
  • Back (or Esc): everything flies back into place.
  • Need you pill: swipe right to approve, left to deny, hold for details.
